# Иконки приложения

Здесь лежит исходник иконки и скрипт нарезки. В `frontend/icons/` эти файлы
не кладём: всё оттуда Capacitor копирует внутрь APK, а исходник и мастер на
1024px приложению не нужны — это лишние сотни КБ в сборке.

| файл | зачем |
|---|---|
| `icon-source-bubble.jpg` | исходник (мыльный пузырь, 1000×1000): чистый чёрный фон, без скруглений и водяных знаков |
| `icon-1024.png` | мастер для сторов: квадрат без альфа-канала, без своих скруглений (маску накладывают сами iOS/Android) |
| `build_icons.py` | нарезка всех размеров из исходника |

Прежний исходник (узел на тёмно-синей плитке) требовал инпейнтинга углов и
обрезки водяного знака генератора — в текущем скрипте этого нет, он написан
под чистый исходник. Меняя исходник на новый со своими артефактами — старую
логику придётся вернуть или переписать заново.

## Перегенерация

```
python store-assets/build_icons.py
```

Скрипт кладёт результат в `store-assets/icons_out/`, оттуда файлы копируются
руками:

* `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`,
  `app.ico` → `frontend/icons/`
* `mipmap-*/` → `android/app/src/main/res/mipmap-*/`
* `icon-1024.png` → сюда же, в `store-assets/`

Путь к исходнику задан константой `SRC` в начале скрипта.

## Что важно помнить

* **iOS**: иконка в сторе — квадрат 1024×1024 **без прозрачности и без
  собственных скруглений**. Система маскирует сама; если углы вшиты в
  картинку, получится двойная рамка.
* **Android**: адаптивная иконка = подложка (`@color/ic_launcher_background`,
  сейчас `#0C1422` — фон приложения) + передний слой
  `ic_launcher_foreground.png` в кадре 108dp, где содержимое живёт в
  центральных ~65%. Всё, что за пределами, любая маска лаунчера отрежет.
* **maskable для PWA**: знак ужат в безопасный круг, иначе на Android
  в веб-версии иконку обрежет по краям.
* Цвет подложки в `values/ic_launcher_background.xml` должен совпадать с
  фоном, которым залит foreground-слой — иначе вокруг знака виден шов.
* **Полупрозрачный/тёмный внутри объект — вырезай по ФОРМЕ, не по яркости.**
  У пузыря середина фотографически такая же тёмная, как фон; альфа-маска
  по яркости пикселя приняла бы её за фон и прорезала бы в диске дыру
  кружевом. Раз объект физически круглый — вырезаем сплошным эллипсом по
  измеренным границам силуэта, содержимое (свет/цвет) внутри уже не важно.
