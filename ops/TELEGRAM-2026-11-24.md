# Telegram-версия: что сделано по ТЗ (24.11.2026)

Источник: `docs/TELEGRAM-TZ.md`. Ничего не выложено на сервер, ничего не закоммичено. Проверка: `npm test` 111/0 (из них 25 новых в `tests/telegram.test.cjs`), `node tests/run-browser.mjs` 37 сценариев, 0 упавших (новый — `tests/browser-telegram.js`). Реальный Telegram, телефоны и настоящий бот не проверялись.

## Сделано (проверено автотестами)
- Проверка `initData`: HMAC, `timingSafeEqual`, `auth_date` ≤ 24 ч, бот-пользователь, метка `start_param` (`lib/telegram-auth.js`).
- Вход `POST /api/auth/telegram`, аккаунт без почты, согласие с источником `telegram`, возраст 16+ и оферта на экране входа.
- Привязка: с сайта (код 10 минут, хеш), из Telegram по коду из письма (5 попыток), замена Telegram-аккаунта с предупреждением, запрет при деньгах, отвязка только если есть другой вход, журнал замен.
- Удаление аккаунта без пароля — по свежей подписи Telegram; бот пишет «Аккаунт удалён».
- Бот (webhook с секретом): /start (в т.ч. link_), /today, /stats, /remind, /invite, /stop, /help; кнопки «Сделал», «Минимум», «Пропуск дня»; отметка идёт через ту же `markDay`, что и приложение; чужая кнопка и закрытый день отклоняются; в группах бот молчит.
- Очередь: идемпотентность, 429 по `retry_after`, 403 → пауза и дубль денежных на почту, не больше 4 в день, тихие часы, расписание по поясу аккаунта (утро, вечер, последний шанс, итог дня, серии 7/30/100, пруф, друг, неустойка).
- Мини-приложение `/tg/`: страница собирается из `index.html`, SDK и CSP только там, `frame-ancestors` для Telegram Web, основной сайт по-прежнему `DENY`; токен только в памяти; BackButton, MainButton, подтверждение закрытия, цвета, safe area, внешние ссылки через `openLink`, `requestWriteAccess`, приглашение в бота вместо копирования.
- Метки: `inv_` превращается в дружбу, `ck_` открывает пруф (последнее не покрыто тестом).

## Сделано, но не проверено тестом
- Добавление почты и пароля к аккаунту Telegram (`/api/telegram/add-email`).
- Экран «Напоминания в Telegram» в профиле, `addToHomeScreen` после 3-го дня, тактильный отклик, открытие пруфа по `ck_`.
- Рассылка о новой редакции оферты: функция `queueLegalNotice` есть, запускать её нечем.

## Не сделано
- Пруф файлом в ответ боту; `shareMessage`/`shareToStory`/`SecureStorage` (нужна сверка с документацией Bot API; вместо этого ссылка `t.me/share`).
- Вся «вторая очередь»: депозит в Telegram, групповые челленджи, inline, парные обещания, Stars, кабинет автора `cr_`.
- Свои шторки вместо `confirm()` (осталось в 4 местах `script.js`), вход через Google внутри Telegram.
- Темы: цвета Telegram следуют текущей теме, а не всегда «Путь».
- Юридический раздел 11 и этапы 1, 4: ПД, Роскомнадзор, оферта, опрос людей, регистрация бота в @BotFather, проверка статуса Telegram в РФ.
- Ручная проверка на Android, iOS, Desktop, Web.

## Что нужно решить или сделать вам
1. Создать бота в @BotFather, положить `ops/telegram.env.example` в `/etc/disbit/<имя>-telegram.env` (600), выставить webhook с `secret_token`.
2. Список `frame-ancestors` и сигнатуры SDK взяты по памяти: сверить с core.telegram.org.
3. Конфликт в ТЗ: «Последний шанс» уходит в 23:00, а тихие часы по умолчанию 23:00–08:00. Я сделал для него исключение; скажите, если нужно иначе.
4. Отклонение: в метке `ck_` вместо id обещания короткий id кнопки (id обещания может быть длиннее 64 знаков).
5. Файл `docs/TELEGRAM-TZ.md` и все изменения не закоммичены.
