# Проверка на телефоне перед магазинами — чек-лист

Для каждой строки записать: устройство, версию приложения (или «сайт»), результат, при сбое — скриншот или запись экрана.
Использовать **отдельный тестовый аккаунт**; основной аккаунт не удалять. Шаги с деньгами — только на свои карты.

## 0. Подготовка

- [ ] Сервер обновлён: `https://disbit.ru/api/ready` показывает нужный коммит.
- [ ] APK собран свежим `.\ops\release-android.ps1`, подпись — сертификат `7e95ad23…befd701` (скрипт печатает при сборке).
- [ ] Старая версия на телефоне **не удалена** перед установкой — новая ставится поверх (проверка, что подпись совпадает и данные сохраняются).

## 1. Установка и запуск (Android)

- [ ] APK устанавливается поверх предыдущей версии, вход сохранился.
- [ ] Холодный запуск без белого экрана и ошибок; вкладки «Сегодня / Марафон / Друзья / Профиль» открываются.
- [ ] Номер версии в профиле совпадает с собранной.
- [ ] Поворот, сворачивание и возврат в приложение — состояние не теряется.

## 2. Вход и аккаунт

- [ ] Регистрация по почте: письмо с кодом пришло, код принят.
- [ ] Вход через Google в приложении (не только на сайте).
- [ ] Выход и повторный вход — обещания на месте.
- [ ] Восстановление пароля по почте.

## 3. Обещания

- [ ] Создать обещание (ежедневное и «N раз в неделю»), отметить сегодня, отменить отметку.
- [ ] «Отметить минимум», «Пропустить день» (счётчик «осталось N» уменьшается).
- [ ] Пруф фото и видео: снять, отправить, статус «на проверке».
- [ ] Отметить вчерашний день нельзя (только сегодня по часовому поясу аккаунта).

## 4. Друзья и приглашения (исправление 23.11)

- [ ] Карточка обещания → «…» → «Позвать по QR / ссылке» — шторка с QR открывается **поверх** карточки.
- [ ] «Закрыть» в приглашении возвращает в карточку обещания.
- [ ] «…» → «Делать с другом» — шторка выбора друга открывается поверх карточки.
- [ ] «Поделиться ссылкой» открывает системное меню; в Telegram, WhatsApp, iMessage видно превью с ником.
- [ ] Друг открывает ссылку на Android с установленным приложением — открывается приложение (App Links), а не браузер.
- [ ] Друг без аккаунта: ссылка → вход/регистрация → приглашение не теряется, обещание появляется у друга.
- [ ] Вкладка «Друзья»: «Скопировать ссылку», «Поделиться», прогресс друзей обновляется.

## 5. Деньги — тест на 1 ₽ (главный блокер)

- [ ] Принять действующую редакцию документов, если приложение попросит.
- [ ] Пополнить на 1 ₽ (к оплате 1,04 ₽) → страница ЮKassa → оплата → возврат в приложение.
- [ ] Депозит показывает 1 ₽ без ручного обновления (или после «Проверить»).
- [ ] Прервать оплату на середине → «Продолжить оплату» ведёт к тому же платежу, второй не создаётся.
- [ ] Денежное условие на обещании: отдельное согласие, «действует с завтра».
- [ ] Вернуть 1 ₽ на карту → статус возврата; деньги пришли на карту (до 5 рабочих дней).
- [ ] Касса оператора (`review.html`): пополнение и возврат видны в списке «без чека».
- [ ] Чек в «Мой налог» на 1,04 ₽ оформлен, при возврате — скорректирован; операция отмечена в кассе.

## 6. Профиль и данные

- [ ] Экспорт данных: файл скачался и открывается, в нём нет чужих данных и паролей.
- [ ] Удаление **тестового** аккаунта с подтверждением паролем → выход, повторный вход невозможен.
- [ ] Удаление при ненулевом депозите — приложение объясняет, что сначала нужен возврат.

## 7. Блокировка приложений (если включена в сборке)

- [ ] Выдача разрешений (специальные возможности / статистика использования) проходит по подсказкам.
- [ ] Пропуск обещания с наказанием «блокировка» → выбранное приложение блокируется, остальные — нет.
- [ ] После выполнения или окончания срока — разблокировка; перезагрузка телефона не ломает состояние.
