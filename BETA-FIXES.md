# Disbit: исправления беты, 23 октября 2026

## Изменения

- «Сегодня» показывает все марафоны отдельными сценами; экран марафона по-прежнему показывает выбранный маршрут. Градиенты SVG и таймеры движения независимы.
- Новые обещания: штраф по умолчанию создателям. При редактировании сохраняется ранее выбранный получатель.
- «Минимум» всегда открыт, без слова «запасной». Описание и отметка минимума сохраняются в SQLite и восстанавливаются после перезагрузки.
- Срок и число шагов марафона: только барабан, клавиши и кнопки +/-; дата очищается кнопкой «Без срока». Отмена не сохраняет черновик.
- Выбираемая шляпа заменена кепкой, прежний выбор переносится в кепку. «По сцене» сохраняет походную шляпу и специальную экипировку маршрутов.
- Пояснения возле удерживаемых кнопок скрыты визуально; кнопки больше не сжимаются. Удержание пальцем, Enter и скринридер поддерживаются.
- История: прошлые и будущие дни доступны только для просмотра. Сервер тоже отклоняет отметки не за сегодня.

## Подтверждение выполнения

1. Нажатие отметки открывает предварительный полноэкранный шаг.
2. Можно отправить фото/видео или нажать «Пропустить · осталось N из 5».
3. Пять пропусков общие для аккаунта за календарный месяц, не для каждого обещания. Это отдельный лимит от грейс-дней.
4. После исчерпания лимита фото/видео обязательно. Закрытие экрана, Escape и перезагрузка не засчитывают неподтверждённый шаг.
5. Только после успешного подтверждения и сохранения отметки начисляются выполнение, шаг и бит. При ошибке записи можно повторить действие без второго расхода пропуска.
6. Отмена/удаление обещания не возвращают использованный лимит. Повтор одного запроса идемпотентен. На новый месяц доступно снова пять.
7. Загруженный пруф в статусе pending допускает отметку; автоматическая проверка достоверности фото не реализована. Админ-модерация остаётся отдельным механизмом.

Сервер фиксирует IANA-часовой пояс аккаунта при первом обращении к новому правилу; использует реальные серверные часы. Если клиент не передал пояс, применяется Europe/Moscow. Смена заголовка позже не открывает прошлые дни. Автоматическая смена пояса при поездке не реализована; при несовпадении дня интерфейс просит обновить приложение.

Создание обещания с произвольной историей теперь отклоняется: иначе запрет прошлых отметок обходится импортом. Уже хранящаяся история не удаляется. Повторный POST существующего id возвращает 409.

## Проверено

Итог локального прогона: `npm test` 13/13, целевой браузерный набор 20 групп без ошибок JavaScript. Дополнительно проверено настоящее удержание указателем 1 секунду; Enter проверяется в наборе.

- Серверные тесты: принадлежность данных, строгая дата, счётчик, пропуски, конкурентный последний слот, повторные запросы, отсутствие возврата квоты, загрузка пруфа при исчерпанной квоте, месяц/часовой пояс, сохранение минимума.
- Браузер: два марафона через форму, повторный вход, минимум, получатель, барабаны/отмена/очистка, кепка, прошлый день, Escape/закрытие камеры, квота, загрузка PNG, размеры 320/390/1280, reduced motion. Скриншоты в test-results/beta-*.png.
- Изменённый UI проверен по Web Interface Guidelines: подписи полей/доступность клавиатурой, фокус, скрытые пояснения, состояния ошибок, отсутствие горизонтального переполнения. Сохранены токены Disbit; навыки дизайна использованы для качества, без смены фирменного стиля.

## Перед публикацией

Нужны резервная копия БД и совместное обновление frontend/backend. Миграции добавляют users.time_zone, habits.minimum_action, completions.minimum и таблицу proof_skips. Старые клиенты без нового подтверждения получат отказ при отметке.

В этой работе нет деплоя, коммита/пуша, сборки APK/iOS или проверки камеры на физическом устройстве. Нативная блокировка и реальные платёжные операции не менялись. Исторические браузерные наборы с прежними правилами требуют обновления; текущий результат относится к новому целевому набору и npm test.
