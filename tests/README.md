# Тесты Disbit

Обновлено 17 ноября 2026. Все проверки работают только с локальными временными базами и тестовой почтой; production и настоящие платежи не затрагиваются.

## Серверные тесты

```powershell
npm test
```

Запускает `tests/*.test.cjs` (Node ≥ 22.13, установленный `backend/node_modules`). Каждый файл поднимает свой сервер на отдельном порту с новой SQLite-базой.

Регистрация проверяет MX-запись почтового домена через DNS. Без доступа к DNS тест `audit-remediation` падает на регистрации — это ограничение окружения, а не кода.

## Браузерные сценарии

```powershell
npm i -g playwright
npx playwright install chromium
node tests/run-browser.mjs                       # все сценарии
node tests/run-browser.mjs tests/browser-intro.js # один сценарий
```

Для каждого сценария запускается свежий fixture-сервер (`fixture-server.mjs`, `sandbox-ui-fixture.mjs` или `recovery-fixture.mjs`) на порту, указанном в самом сценарии. Нужный вход в тестовый аккаунт и переменные окружения заданы в таблице `special` внутри `run-browser.mjs`. При падении снимок экрана сохраняется в `test-results/fail-<сценарий>.png`.

`browser-password-recovery.js` — вторая половина ручной проверки: код восстановления берётся из тестовой почты той же сессии, поэтому общий прогон его пропускает.

17 ноября удалены восемь исторических наборов (`browser-beta`, `-beta-edge`, `-beta-grace`, `-journey`, `-motion`, `-motion-actions`, `-insights`, `-path-ui`). Они опирались на старое содержимое фикстуры и прежний интерфейс (поле шагов без барабана, подсказку удержания, правку прошлых дней) и не запускались. Актуальное поведение покрывают `browser-beta-fixes.js` (20 групп) и остальные сценарии.

## Что не заменяют эти проверки

Физические Android/iOS, настоящую камеру, установку поверх старой версии, настоящие Google-вход, письма и платежи, приёмку production.
