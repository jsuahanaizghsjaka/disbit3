# Disbit для iOS

Нативный контейнер Capacitor 8.5.3, bundle ID `io.disbit.app`, версия 1.0.3 (4).
Web-файлы включаются в приложение; API — `https://disbit.ru`.

## Синхронизация и сборка

Из корня проекта:

```sh
npm ci
node scripts/sync-ios.mjs
npx cap open ios
```

`sync-ios.mjs` также исправляет разделители путей Swift Package Manager после запуска на Windows.
Сборка выполняется на Mac с Xcode. В GitHub Actions есть отдельная сборка для
симулятора без подписи; её результат не является IPA для телефона или TestFlight.

Для физического устройства выбрать свою Apple Developer Team в Signing & Capabilities,
проверить доступность bundle ID, настроить signing и выполнить Archive в Xcode.
Секреты Apple и сертификаты не включать в репозиторий.

## До распространения

- Развернуть совместимый сервер и проверить вход, обещания, пруф, квоту и покупки за биты.
- Проверить на iPhone запросы камеры и микрофона, запись, отказ в разрешениях, клавиатуру,
  safe area, фон, возврат в приложение и уведомления.
- Заменить стартовые иконку/заставку Capacitor на утверждённые ресурсы Disbit.
- Подготовить App Store Connect, подпись, privacy disclosures и проверку privacy manifests
  используемых SDK. Тексты разрешений камеры и микрофона уже добавлены в Info.plist.
- Apple/Google Sign-In, системная блокировка приложений и реальные платежи этим
  контейнером не реализуются и требуют отдельных этапов.

Компиляция симулятора не заменяет эти проверки.
