# Disbit — план ускорения и плавности

Аудит от **28 октября 2026**, исходная версия `e9d98b5` / Android 1.0.6. Работа начата; приведённые ниже планы ещё не приняты целиком и не опубликованы.

Начать с [полного анализа и ТЗ](DISBIT-PERFORMANCE-AUDIT-AND-SPEC.md): в нём измерения, причины задержек, приоритеты, ограничения и общий маршрут.

Состояние на 1 ноября: частично реализованы переиспользование форматтера, обновление активного экрана, параллельные чтения при запуске, черновики, барабан, переключатели, фокус шторок и освобождение камеры. Убраны повторные подсчёты прогресса при построении списка марафонов; чтения с разными часовыми поясами не объединяются. Остальные части планов, проверка на устройствах и выпуск остаются открыты. В синтетическом браузерном сценарии медиана `render()` на 5 привычках / 90 днях составила 2,6 мс против исходных 42,7 мс; это измерение функции на локальных данных, не показатель скорости или FPS телефона.

Рекомендуемый порядок: **база 008 → 001 → 002 → 003 → 004/005 → 006 → 007 → финальная приёмка 008**. При отдельном ресурсе улучшение мобильного фокуса из 005 можно сделать раньше; согласовывать общие изменения `script.js`. Сохранение формы описывается в 003, его не дублировать в 005. Модель progress/streak принадлежит 002, её не создавать второй раз в 006.

Каждый план содержит точные текущие места кода, целевые значения, пошаговые изменения, границы и проверку. При отличии исходников от `e9d98b5` обновить привязки до исполнения. Существующие тёмные цвета, Glass Light, подробный персонаж и бизнес-правила сохраняются.

Браузерные сценарии запускать только в изолированной сессии и на синтетических данных. Нельзя направлять их на аккаунты production. Android-замеры навигации не меняют обещания, покупки и платежи.

Пример запуска основного сценария в PowerShell проекта:

```powershell
$env:DISBIT_HISTORY_FIXTURE = '1'
node tests/sandbox-ui-fixture.mjs
```

Во втором терминале:

```powershell
playwright-cli -s=disbit-perf open http://127.0.0.1:3399
playwright-cli -s=disbit-perf resize 384 774
playwright-cli -s=disbit-perf run-code --filename=plans/runtime-performance-audit.js --raw
playwright-cli -s=disbit-perf run-code --filename=plans/date-format-audit.js --raw
playwright-cli -s=disbit-perf close
```

Остановить fixture через Ctrl+C. Скрипт создаёт временную БД с вымышленными пользователями и ключом тестового вида; настоящий платёжный провайдер не вызывается. Сам benchmark изменяет только память изолированной страницы. Форматтер можно проверить и через простой статический localhost-сервер без аккаунта.

## Ограничения

Локальные миллисекунды и CPU throttle не являются измерением A22. `gfxinfo` не является прямым FPS или INP; Activity TotalTime не является готовностью веб-интерфейса. Полноценные GPU/JS-трассы, камера, iPhone, Android 15/16, полевая сеть и полевые метрики включены в будущую приёмку. Подробные оговорки и точные цифры находятся в основном анализе.
